# Product Details Using Structures in C

## Project Description

A simple C program that uses structures to store and display product details. It also calculates the total amount based on the price and quantity.

## Features

- Enter product details
- Display product information
- Calculate total amount

## Technologies Used

- C
- Structures
- Variables
- Arithmetic Operations

## How to Run

Compile and run the `product_details.c` file using a C compiler.
